# 玄机 更新日志

> 玄机(原名「工具坞 QuickDock」)—— 纯本地运行的 Windows 桌面工具启动器。
> 不联网、不上传数据、无数据库,所有配置就是一个本地 JSON 文件。
> 本文件记录每个版本的功能变化,新版本在前。

---

## v2.2.0 · 2026-09-29 「P1 四模块落地」

P1 规划中的四大模块全部转正:**日志中心 / 命令库(Command Vault) / 资源中心 / 环境健康检查**;tools.json 配置结构升级到 **v2.1**(自动迁移,旧文件三代滚动备份)。

### ✨ 新增

- **全局呼出快捷键可自定义**(设置 → 窗口行为):录制式改键(点击后按组合键即录入,Esc 取消),支持 Ctrl/Alt/Shift/Super + 字母/数字/F 键/Space;可禁用(不注册任何全局键)/一键恢复默认;注册结果实时反馈(被其他程序占用时提示换键);主进程热更新(改键即时生效,无需重启)
- **v2.1 配置迁移**(Task #14):v1→v2.0→v2.1 两级串行自动迁移;迁移前滚动备份 `bak.1/2/3` 三代轮换;静默完成,启动后 toast「配置已升级到 v2.1」;新增 `checks` / `tools[].checkIds` / `settings.run` / `settings.log` / `settings.healthCheck` 字段(全部带默认值,旧数据行为不变);健康检查预设种子(Java/Python/pip/Git)仅在用户无自定义检查时写入
- **日志中心**(Task #15):所有工具进程输出 jsonl 落盘(`logs/<toolId>.jsonl`),info 级按 errorPatterns/warnPatterns 正则重判等级;独立全屏视图:左侧工具列表(行数/错误/警告徽标/大小/最近写入),右侧四维过滤(等级分段/时间范围/关键字/正则高亮)+ 虚拟滚动(1 万行上限流畅渲染);单文件 5MB 自动轮转(保留一代),默认 14 天过期清理(启动 10s 首巡 + 每 6h);导出前敏感数据二次确认;日志保留策略与判定正则均可在设置页调整
- **命令库 Command Vault**(Task #16):命令模板 + `{{变量}}` 占位,渲染优先级 **工作空间变量 > 全局变量 > 运行时询问**(ask 表单带 varMemory 记忆上次填写);运行弹窗实时预览渲染结果,未填变量高亮;**危险命令双保险** —— 渲染层命中 dangerPatterns 强制勾选确认,主进程运行前兜底再扫一遍(未确认命中直接拒绝);运行 = 隐藏 `cmd /c`,输出进日志中心全链路;运行统计(runCount/lastRunAt);标签/收藏/搜索;Ctrl+K Enter 直达运行弹窗 / Shift+Enter 直接复制渲染结果;工作空间弹窗支持维护空间变量
- **资源中心**(Task #17):Payload/字典/脚本等文件的**引用式**管理(只存路径,删除记录不动文件);列表/网格双视图 + 标签/收藏/搜索过滤;悬空引用批量检测标红;文本白名单(20 种扩展名)预览(≤1MB,前 200 行截断提示),非文本类型仅打开/定位;Ctrl+K 资源条目改为「打开」
- **环境健康检查**(Task #18):三类检测模板 —— **exec**(跑命令 + expectRegex 命中输出判定,超时上限 30s)/ **port**(TCP 连通性 3s)/ **file**(路径存在性);结果 TTL 缓存(settings 可调);模板 CRUD 在设置页,工具编辑弹窗新增「环境检查」标签页挂载 + 就地新建 + 试跑;**启动链路拦截**:挂载了检查的工具启动前自动跑检查,红项 + blockOnFail=true 默认阻止启动(弹面板逐项展示 + 修复建议 + 强制启动覆盖);blockOnFail=false 仅警告放行
- **文档**:`docs/data-model.md`(v2.1 数据模型)+ `docs/ipc-api.md`(全量 IPC 通道参考)

### 🔧 优化

- 侧边栏「规划中」仅剩 代理管理 / 测试记录;日志中心入口迁入「工具箱」分区(命令库/资源中心/日志中心);工具卡片「⋯」菜单新增「在日志中心打开」
- runner 输出等级统一经 logstore 重判后分发(内存日志/实时推送/落盘三路一致)
- 设置页新增:日志中心区块(保留天数/单文件上限/判定正则)、环境健康检查区块(拦截开关/缓存时长/模板管理)

### 🐛 修复

- **事件订阅泄漏(越用越卡的元凶)**:preload 的 `onRunnerLog` 等三个订阅直接返回 `ipcRenderer.on()` 的返回值(ipcRenderer 本身而非退订函数),组件卸载时 `offLog?.()` 必然 TypeError(`offLog is not a function`),监听器永远注销不掉 —— 每次进出日志中心/打开日志面板叠加一层监听,旧闭包持有已卸载组件状态,每条日志触发 N 次无效处理。现三个订阅统一返回真正的退订函数
- **渲染进程崩溃自愈**:`render-process-gone`(crashed/oom)后此前仅记日志,窗口白屏冻结需手动杀进程;现延迟 0.8s 自动重载页面恢复
- **GPU 连环崩自动降级**:GPU 进程单会话连续崩溃 ≥3 次时自动写 `gpu-fallback.flag`,下次启动自动软渲染(删除该文件可恢复硬件加速);部分显卡驱动上硬件加速会连环 0xC0000005 并连带渲染器崩溃,是历史「卡死/白屏」的主要来源
- **.lnk 图标丢失(拿到通用快捷方式白框图)**:图标提取直接对 .lnk 文件做 `app.getFileIcon`,拿到的是「白纸+蓝箭头」通用快捷方式图标而非目标程序图标(所有 lnk 工具共用同一张图);现先经 `shell.readShortcutLink` 解析真实目标再提取,路径先 normalize(修复 `C:////` 四连斜杠脏路径),空图/异常小图不落缓存避免坏图永久存续;已生成的坏缓存删除后自动重建
- **悬空/损坏 lnk 的白框图误判**:目标丢失的坏 lnk(readShortcutLink 抛异常)回落对 lnk 本身提取仍会拿到通用白框图(它是真实非空图,空图检测挡不住);现加入**默认图指纹黑名单** —— 预先对不存在的路径提取一次取得系统默认图标指纹,提取结果命中指纹即视为失败(不缓存,磁盘旧缓存命中指纹自动删除重建,老坏缓存自愈);坏 lnk 不再回落提取,改用首字母占位(诚实提示 > 误导性白框);lnk 解析失败时追加 `iconLocation` 图标资源兜底
- **命令库 emoji 误触即保存**:点选表情图标会立即 `save()` 并弹「命令已保存」toast,与「显式保存」设计不一致;现点选仅改表单并点亮「有未保存的修改」,统一由「保存修改」按钮提交

## v2.0.0 · 2026-09-29 「安全操作台」

定位升级:从通用工具启动器升级为**网络安全人员个人安全操作台** —— 面向渗透测试 / 红队 / DevSecOps 工作流,以「工作空间」为核心组织一次任务的全部上下文。本轮为 P0 落地:P1(命令模板 / Payload 库 / 日志中心 / 健康检查 / 代理管理 / 测试记录)与 P2(数据库 / Proxy)仅含数据结构与侧边栏占位入口。

### ✨ 新增

- **首页工作台**:启动默认进入工作台 —— 问候语 + 今日启动统计、最近的工作空间(一键回到现场)、最近使用、快速操作(新建工作空间 / 打开全部工具 / 唤起命令面板);可在设置中把默认页改为「全部工具」或「上次视图」
- **工作空间(Workspace)**:一次渗透任务的全部上下文 —— 工具引用(非复制,工具删除自动清理引用)、项目目录(一键在资源管理器打开)、目标变量(P1 命令模板数据源);进入空间绝不自动拉起任何工具,「启动环境」是显式动作:勾选后按顺序串行拉起(间隔 0.5s),各工具自身的二次确认 / 管理员权限照常生效
- **多启动配置(LaunchConfig)**:每个工具可配多套启动配置(名称 / args / cwd / env / 管理员 / 运行方式),任设一条为默认;卡片单击 = 默认配置,「⋯」菜单可选其他配置运行;某字段留空自动回落工具基础设置(兼容 v1 旧字段)
- **命令面板升级**:Ctrl+K 分组搜索 —— 工具(名称/备注/分类/拼音)/ 工作空间 / 命令 / 资源路径,命中片段高亮;搜索直达工作空间与常用命令,路径不变零新增步骤
- **v1→v2 数据迁移**:首次启动自动升级 tools.json 到 v2.0 结构 —— 原文件备份为 `tools.json.bak`,旧工具自动生成「默认启动」配置(继承原有 runMode / 管理员 / 日志捕获行为),字段兜底防旧配置缺字段
- **P1/P2 占位入口**:侧边栏「规划中」分区(命令行 Combos / Payload·资源 / 日志中心 / 环境健康检查 / 代理管理 / 测试记录),点开显示「开发中」引导页;数据结构(`commands` / `resources` / `globalVars` / `proxy` / `sessions`)已在 tools.json v2.0 中预留,设计预案见 `docs/future-database.md`
- **敏感字段加密能力**:主进程新增 `secret:` 域,基于 Electron safeStorage(Windows DPAPI)加解密,存储格式 `{ encrypted: true, value: "<base64>" }`;本期提供能力与数据结构,Proxy 凭据(P2)/ secret 变量(P1)UI 接入后启用

### 🔧 优化

- **管理员运行加固**:统一走 ShellExecute `runas`(UAC 确认),废除 cmd `start` 提权 hack
- 导出配置前弹敏感数据提示(内网地址 / 目标信息等,提醒保管)
- 主进程按领域拆分 `modules/`(workspace / launcher / secret),渲染层新增 workspace / launchConfig / searchIndex 三个独立 store
- 应用日志:单份 5MB 自动截断,记录前对疑似凭据脱敏
- 修复:设置同步把 Vue reactive Proxy 直接传入 IPC 导致的 `An object could not be cloned`(现已展开为普通对象;workspace patch 通道增加防御性深拷贝)
- 修复:侧边栏底部按钮组(sticky + 半透明渐变)在导航内容超高时悬浮遮挡「规划中」列表项造成视觉重叠 —— 改为导航区独立滚动、footer 常驻底部

### 📌 范围调整

- 砍除原规划的插件系统;VPN 检测不做
- 数据库(P2)仅预留结构与设计文档,本期仍是纯本地 JSON

## v1.3.0 · 2026-09-29 「组合与智能」

更名:「工具坞 QuickDock」正式更名为 **玄机**。首次启动自动把旧数据目录(`%APPDATA%\工具坞 QuickDock`)的分类、工具、图标缓存与历史日志迁移到新目录(`%APPDATA%\玄机`),无痛升级。

### ✨ 新增

- **工具组合(一键工作环境)**:把多个工具打包成组合(如「Web 开发环境」= VS Code + Node + Chrome + Postman),侧边栏一点全部按勾选顺序串行拉起(间隔 0.4s)。支持创建 / 编辑 / 右键启动 / 右键删除,删除组合不影响工具本身
- **全局快捷键 `Ctrl+Space`**:系统级注册,托盘与最小化状态下同样生效 —— 前台按下隐藏到托盘,后台按下呼出窗口并直接聚焦命令面板;退出应用自动释放热键
- **智能最近使用**:侧边栏新增「🕘 最近使用」视图;智能首页含按时段问候语、今日启动统计、「📌 继续昨天的工作」一键续上、卡片显示相对时间徽标(刚刚 / 3 小时前 / 昨天)
- **AI 预测启动**:根据近 7 天启动历史,在常用时段(±90 分钟)预测你可能要用的工具并一键直达;今天已启动过则自动安静;支持「不再提醒」
- **使用报告**(设置页):工具总数 / 今日启动 / 本周活跃三统计块 + 近 7 天 Top 5 渐变条形图
- **工具健康检查**(设置页):进入设置自动全库扫描目标文件存在性,失效工具列出路径并提供「打开目录」修复入口,支持手动重新检查;此外每次运行工具前也做前置检查,文件丢失时弹框引导定位而不是报晦涩错误
- **沉睡工具**(设置页):自动清点超过 30 天未启动的工具

### 🔧 优化

- 组合一键启动跳过单个工具的「运行前二次确认」(点击启动即为明确意图,避免连续弹框)
- 预测在每次启动后即时重算
